Priority order: check top to bottom, first match wins.

0. Trusted senders (highest priority, override every rule below,
   regardless of subject)

   These senders mail through batch mailing lists, so the address shown
   in the inbox list is the list (Batch25@ / BSCS25@isb.nu.edu.pk) and the
   real address is in reply-to, which is NOT visible without opening the
   mail. So match on the display NAME shown in the list; keep the direct
   addresses as a fallback.

   sender name contains "Placement @ One Stop" / "One Stop Islamabad"
     OR sender email = placement.isb@nu.edu.pk       -> Placement
   sender name contains "Student Affairs"
     OR sender email = studentaffairs.isb@nu.edu.pk  -> Announcement
   sender name contains "Amir Rehman"
     OR sender email = amir.rehman@nu.edu.pk         -> Announcement

   subject contains "Competition", "Hackathon", "Hack Summer", "Build with AI"
     -> Hackathon

   but no clear keyword match
     -> send to LLM for a Hackathon / Not-Hackathon decision
        (LLM sees full sender + subject + snippet)

2. Academics
   sender domain = classroom.google.com
   OR sender display name contains "(Classroom)"
     -> Academic

3. Announcement
   sender email = studentaffairs.isb@nu.edu.pk
   OR sender email = amir.rehman@nu.edu.pk
   OR subject contains "Announcement" or "Important Announcement"
     -> Announcement

4. Placement Offer
   sender email = placement.isb@nu.edu.pk

     -> Placement

     -> Placement
